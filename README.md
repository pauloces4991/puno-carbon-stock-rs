# puno-carbon-stock-rs

R pipeline for carbon stock estimation in high-Andean ecosystems (bofedales, pajonales, queñua forests, bare soil, and water bodies) in the Puno region, Peru, using Sentinel-2 imagery, spectral indices, and Random Forest classification.

## Overview

This repository documents the full analytical pipeline used to estimate and economically value carbon stock across high-Andean vegetation units in Puno (2024–2025), combining remote sensing, machine learning classification, and carbon price scenario modeling (MERESE/MVC framework).

## Pipeline

The complete workflow is contained in `puno_carbon_stock_pipeline.R` and covers six stages:

1. **Sentinel-2 download** — OAuth2-authenticated retrieval from the Copernicus Data Space, covering 17 tiles across the Puno department
2. **Preprocessing** — SCL-based cloud masking and seasonal median compositing
3. **Spectral indices** — NDVI, NDWI (Gao), and EVI calculation
4. **Predictor stack** — integration of Sentinel-2 bands, spectral indices, and Copernicus DEM derivatives (elevation, slope, aspect, TWI) into a 13-variable stack
5. **Classification** — Random Forest land cover classification (5 classes: bofedal, pajonal, queñual, suelo desnudo, agua), using field-digitized training polygons
6. **Carbon valuation** — conversion of classified area to carbon stock, evaluated under multiple MERESE/MVC carbon price scenarios

## Requirements

- R ≥ 4.4.1
- Packages: `terra`, `sf`, `randomForest`, `caret`, `httr2`

Install with:

```r
install.packages(c("terra", "sf", "randomForest", "caret", "httr2"))
```

## Setup

Copernicus Data Space credentials must be set as environment variables before running the download step — never hardcoded in the script:

```r
Sys.setenv(CDSE_CLIENT_ID = "your_client_id")
Sys.setenv(CDSE_CLIENT_SECRET = "your_client_secret")
```

## Data

Raw and processed raster data (Sentinel-2 scenes, predictor stacks) are not included in this repository due to file size. They can be regenerated by running the pipeline from step 1, given valid Copernicus Data Space credentials. Training polygons are expected under `data/training/`.
